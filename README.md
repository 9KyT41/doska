# ДОСКА — мыслелов

Ловит мысли у тех, у кого их миллиард и некуда девать.
Локальная доска: поймать мысль голосом, клавой или вставкой → собрать в главы
нитками и цветными рамками → выгрузить чистым текстом в Word/куда угодно.
Без облака, без регистрации, без ИИ-генерации за тебя.

## Зачем
Голова не пишет абзацами — она сыпет обрывками. Белый лист и мигающий курсор —
это барьер. ДОСКА убирает барьер: мысль ловится за одно действие и в исходном
виде (голос сохраняется оригиналом), а порядок и главы собираются потом, руками,
из уже пойманного.

> «Я гемини юзал, но, по итогу, пришёл к тому, что ручками записываю» — первый
> внешний ревьюер. ДОСКА и есть эти «ручки», только без белого листа.

## Быстрый старт (Windows)
1. Скачай или склонируй репу.
2. Запусти `start-server.bat` (или `npx http-server -p 8080 -c-1`).
3. Открой http://localhost:8080.
4. Меню ☰ → Файл → Создать проект → выбери **папку** (проект = папка, не файл).
5. Нажми `N` или зажми Пробел/пилюлю — поймай первую мысль.

Без сервера тоже работает: открой `index.html` двойным кликом (часть файловых
фич и микрофон будут ограничены политикой браузера).

## Что умеет (альфа)
- Захват: `N` (клава), Пробел/пилюля (голос с живой стенограммой + аудио-оригинал),
  `Ctrl+V` (текст/картинка), drag&drop картинок.
- Композит: драг нод, пан/зум, мультивыделение `Ctrl+клик`, лассо `B`+рамка = блок.
- Граф: нитки «до / после / вместе / доп» из гнёзд; dblclick по нитке = убрать.
- Блоки: цветные рамки-главы с inline-именем, палитрой и крестиком.
- Экспорт: «Чистый текст (.txt)» — мысли по порядку глав, картинки игнор, у аудио
  берётся расшифровка; результат в файл и в буфер обмена.
- Проект = папка: `data.json` + `media/` + `trash.json`; переносится флешкой.

## Порядок компиляции (правило приоритетов)
1. Блоки с нитками внутри = главы (имя блока = заголовок).
2. Свободные цепочки ниток.
3. Блоки без ниток.
4. Остальное в порядке создания.
Внутри — порядок по ниткам; «вместе» = ансамбль в один шаг; «доп» = аннотации.

- Агент-помощник и провайдеры ИИ внутри — опционально, по желанию автора.
